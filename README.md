# Projeto com JPA para Persistência de Dados

Este projeto utiliza JPA (Java Persistence API) para mapeamento objeto-relacional, substituindo o uso de JDBC para melhorar a persistência de dados. Este README fornece uma visão geral do projeto, suas tecnologias principais e como configurar e usar localmente.

## Tecnologias Utilizadas

- **JPA (Java Persistence API)**: Especificação do Java para mapeamento objeto-relacional.
- **Hibernate**: Framework de mapeamento objeto-relacional utilizado para implementar a JPA.
- **Banco de Dados Relacional** (ex.: PostgreSQL, MySQL): Utilizado para persistência dos dados.

## Funcionalidades Implementadas

- **Mapeamento Objeto-Relacional**: Utilização de JPA para mapear entidades Java para tabelas de banco de dados.
- **Operações CRUD**: Implementação de operações de criação, leitura, atualização e deleção de dados utilizando entidades gerenciadas pelo JPA.
- **Configuração de Repositório**: Troca do uso de JDBC pelo JPA para simplificar e melhorar a persistência de dados no projeto.
